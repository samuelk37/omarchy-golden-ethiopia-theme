# 🇪🇹 Omarchy Golden Ethiopia Theme

A custom Omarchy Linux theme inspired by Ethiopia's rich cultural heritage, iconic lions, traditional art, and warm golden colors.

## ✨ Features

- **Golden color palette** — warm, elegant colors inspired by Ethiopian heritage.
- **Ethiopian-inspired artwork** — custom wallpapers featuring cultural and artistic themes.
- **Custom theme configuration** — includes color, Hyprland, icon, and shell theme settings.
- **Custom preview** — a visual showcase of the theme's appearance.
- **Designed for Omarchy** — created for an Omarchy Linux desktop environment.

## 🚀 Installation

Install **Golden Ethiopia** directly from GitHub using Omarchy's built-in theme installer.

### 1. Install the theme

Open your terminal and run:

```bash
omarchy theme install https://github.com/samishow/omarchy-golden-ethiopia-theme
```

### 2. Apply the theme

Follow the prompts displayed by the installer. If the theme is downloaded but not applied automatically, open Omarchy's theme selector and choose **Golden Ethiopia**.

### 3. Enjoy your desktop

Your Omarchy desktop can now showcase a golden color palette inspired by Ethiopian culture, artwork, and heritage.

### 🔄 Update or reinstall

Run the installation command again if supported by your installed Omarchy version, or use the theme selector to manage installed themes.

**Requirements:** Omarchy Linux and an internet connection.
## 🎨 Customization

You can customize the theme by editing the configuration files, including:

- `colors.toml` — theme colors
- `hyprland.lua` — Hyprland-related configuration
- `icons.theme` — icon theme settings
- `shell.hyprland.toml` — shell appearance settings
- `shell.launcher.toml` — launcher appearance
- `shell.menu.toml` — menu appearance
